Billing settings

How your company's trips are cleaned and measured.

-
Pay the drive to a no-show's pickup point
When an employee doesn't turn up, still pay for driving to where they should have been picked up.
Ignore GPS fixes less accurate than
Pings whose reported accuracy is worse than this are dropped before anything is measured.
Faster than this is a GPS glitch
A ping that would need this speed to get there from the last one is treated as a teleport and dropped.
Trust the real trip end within
If the trip ends further than this from the office, the planned office is used as the end point instead.
Reject a routed piece longer than
A gap whose road route is longer than this is not trusted; it's paid as a straight line and flagged for a look.

Nothing already billed changes

Saving creates the next version; old versions are never edited. Each trip uses the new settings from its next calculation.

Every result says which settings version it used (look for "settings v..." on a trip).
